Privacy Policy: RHC Outreach

Last updated October 19, 2026

RHC Outreach is a personal tool run by Roman Young. It is not a public product. It helps me prepare outreach emails for Ryze Healthcare Consulting, a student club at UC San Diego. The only Google account it connects to is my own.

What it accesses

With my permission, it uses the Gmail API to read messages in my mailbox (to check for replies and avoid contacting someone twice), create email drafts, and apply labels. It does not send email. I review and send every message myself.

How the data is handled

Gmail data is processed on a private server I control. An AI assistant (Anthropic's Claude) helps draft messages and summarize replies. Data is not sold, not shared with advertisers, and not used for any purpose other than the one described above. The access credential is stored on that server and is not shared.

Google API Services User Data Policy

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
